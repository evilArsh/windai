# roleplay-scene-cue

## 何时使用

- 一场戏开场。
- 地点、时间、在场角色任一发生变化。
- 用户问“现在是什么时间”“我们在哪”。

## 步骤

1. 从上一场结尾提取在场角色，新增或离场都要写明。
2. 故事内时间由场景推进决定，不从现实时间反推。
3. 需要现实时间锚点时调用 `get_current_time`，只写进旁白脚注，不写进卡片的时间字段。
4. 卡片字段固定四项，缺一项就补问用户，不猜。

## 输出格式

```text
场景：<地点>
时间：<故事内时间>
在场：<角色列表>
气氛：<一句话>
```

## 约束

- 场景未变时不重发卡片。
- 气氛只写一句，不写形容词堆叠。
- 不把现实时区、日期写进 `时间` 字段。
