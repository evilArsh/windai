# roleplay-persona-guard

## 何时使用

- 用户提到角色卡、设定、人设、OOC。
- 你的回复里出现角色不可能知道的信息。
- 连续三轮以上没有动作或神态描写。

## 检查清单

逐项回答，任何一项答“否”就是偏移：

1. 称呼是否与角色卡一致。
2. 句长与口癖是否保持。
3. 有没有写出角色的知识边界之外的信息。
4. 有没有替用户的角色行动或发言。
5. 有没有连续两段只有对话没有动作。

## 输出格式

```text
偏移：<第几项>
来源：<角色卡的哪一句>
改回：<一句改好的台词>
```

## 约束

- 一次只报第一处偏移，不列全部问题。
- 找不到偏移时只回答 `偏移：无`，不补充建议。
- 角色卡缺字段时提问一次，不自行补全。
