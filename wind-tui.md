# wind-tui开发计划

先规划, 直到没有问题了再出详细计划

## 背景

本库初始版本开发完毕, 现开发 wind-tui app 用于验证,

tui使用合适的tui库开发,先调研最合适的,最后由我决定

## 开发计划

采用渐进式开发,功能从小到大规划

### 对话页面

布局:

```text

┌───────────────────────────────────────────────┬────────────────────────────┐
│                                               │ Layer 1                    │
│                                               │                            │
│                                               ├────────────────────────────┤
│                Content Area                   │ Layer 2                    │
│                (Flex / Fill)                  │                            │
│                                               ├────────────────────────────┤
│                                               │ Layer 3                    │
│                                               │                            │
├───────────────────────────────────────────────┤                            │
│ > Input (height 40)                           │                            │
│                                               │                            │
└───────────────────────────────────────────────┴────────────────────────────┘

```

layer1 展示启用的mod列表,可局部滚动
layer2 展示实例树结构,可局部滚动
layer3 展示事件日志,可局部滚动

input 输入任务指令 ,content area 渲染markdown结果

布局与交互以[宿主应用设计](docs/superpowers/specs/2026-11-12-wind-tui-design.md)为准，两者冲突时以设计文档为准；实施步骤见[wind-tui 实施计划](docs/superpowers/plans/2026-11-12-wind-tui.md)。
